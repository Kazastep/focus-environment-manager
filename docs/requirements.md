# Требования к MVP

## Цель

MVP должен позволять:

1. Запустить desktop-агент.
2. Автоматически собирать данные об активности.
3. Сохранять их через backend.
4. Просматривать базовую статистику.

Архитектура системы описана отдельно:

[Архитектура проекта](architecture.md)

## Функциональные требования

### Desktop Agent

Должен:

- определять активное приложение;
- определять активное окно;
- определять состояние active / idle;
- фиксировать переключения между приложениями.

### Dashboard

Должен отображать:

- общее активное время;
- время по приложениям;
- количество переключений.

### Backend

Должен:

- принимать события от desktop-агента;
- валидировать входящие данные;
- сохранять события в PostgreSQL;
- предоставлять данные для dashboard.

### Database

PostgreSQL должна хранить события активности.

Для MVP событие должно содержать как минимум:

- время события;
- приложение;
- заголовок окна;
- состояние active / idle.

## Не входит в MVP

- авторизация;
- несколько пользователей;
- AI-рекомендации;
- командная аналитика;
- синхронизация между устройствами;
- мобильное приложение;
- сложная аналитика.

# Работа с доской проекта

Работа с доской будет производиться в Github/Projects .

## Статусы

### Задачи на будущее

Задача существует, но пока не планируется к выполнению.

### Готово к работе

Задача понятна и может быть взята разработчиком.

### В работе

Разработчик начал выполнять задачу.

Этот статус устанавливается вручную.

### На проверке

Работа завершена и создан Pull Request.

Если PR связан с Issue, статус устанавливается автоматически.

### Завершено

Pull Request проверен и смержен.

Статус устанавливается автоматически.

## Работа с задачей

Полный цикл:

```text
Issue создан
    ↓
Готово к работе
    ↓
разработчик берёт задачу
    ↓
В работе
    ↓
создаёт ветку
    ↓
делает коммиты
    ↓
создаёт PR
    ↓
Closes #номер_issue
    ↓
На проверке
    ↓
Review
    ↓
Squash and merge
    ↓
Завершено
```

## Связь Issue и Pull Request

Например существует:

```text
Issue #12
Реализовать отслеживание активного приложения
```

Ветка:

```text
feature/12-active-app
```

В Pull Request указываем:

```text
Closes #12
```

GitHub связывает PR с Issue.

После этого:

```text
PR создан
→ Issue переходит в "На проверке"


PR merged
→ Issue закрывается
→ задача переходит в "Завершено"
```

# Focus Environment Manager

**Focus Environment Manager (FEM)** — система для автоматического отслеживания активности пользователя за компьютером и анализа распределения рабочего времени.

Проект разрабатывается командой из трёх человек в рамках университетской проектной деятельности.

## О проекте

Во время работы за компьютером пользователь постоянно переключается между приложениями, отвлекается или делает перерывы. При этом бывает сложно понять, сколько времени действительно было потрачено на работу и как оно распределялось между программами.

Focus Environment Manager собирает данные об активности в фоновом режиме и предоставляет статистику через веб-интерфейс.

Система позволяет узнать:
- сколько времени пользователь активно взаимодействовал с компьютером;
- в каких приложениях он проводил время;
- как часто переключался между приложениями.

Важно: система измеряет компьютерную активность, а не качество работы или реальную продуктивность человека.

## Как работает система

Основной принцип — автоматический сбор данных без необходимости вручную запускать таймер для каждой задачи.

1. **Desktop Agent** отслеживает активное приложение, окно и периоды отсутствия активности.
2. **FastAPI Backend** получает и обрабатывает события.
3. **PostgreSQL** хранит историю активности.
4. **Web Dashboard** получает данные через API и отображает статистику.

Подробнее: [Архитектура проекта](docs/architecture.md).

## MVP

Первая версия проекта ориентирована на реализацию полного цикла: от сбора реальных данных на компьютере до их отображения в веб-интерфейсе.

В MVP входят:
- отслеживание активных приложений и окон;
- определение состояния `active / idle`;
- фиксация переключений между приложениями;
- сохранение событий активности;
- отображение общего активного времени, времени по приложениям и количества переключений.

Первоначально desktop-агент разрабатывается для **Windows**. Система рассчитана на локальный запуск одним пользователем.

Подробный состав MVP, ограничения и критерии готовности: [Требования к MVP](docs/requirements.md).

## База данных

Для хранения данных используется **PostgreSQL 16**, запущенный через Docker Compose.

Backend взаимодействует с PostgreSQL через асинхронный SQLAlchemy.

В базе данных предусмотрены четыре основные таблицы: `users`, `sessions`, `events`, `statistics`.

**Документация:**

- [Настройка и запуск базы данных](docs/database.md)
- [Технические решения по базе данных](docs/decisions/0001-database.md)

Для локального запуска PostgreSQL:

```bash
docker compose up -d
```

Для создания отсутствующих таблиц:

```bash
python -m database.core
```
